# MojiHairpinMaker-kun

VRChat向けの文字ヘアピンをUnity Editorで生成するツールです。

## V2プレビューの導入

Windows 11・Unity 2022.3.22f1向けの [2.0.0-prerelease.1](https://github.com/arcaia-net/mojihairpinmaker-kun-vpm/releases/tag/v2.0.0-prerelease.1) を配布しています。初回利用にはBOOTH購入者向けのアンロックコードが必要です。

1. VCCまたはALCOMに次の一覧URLを追加します。

   `https://arcaia-net.github.io/mojihairpinmaker-kun-vpm/prerelease.json`

2. プレリリースの表示を有効にし、対象プロジェクトの管理画面で `MojiHairpinMaker-kun` の `2.0.0-prerelease.1` を選びます。
3. Unityの `Tools → MojiHairpinMaker-kun` から開きます。lilToonが入っていない場合は、シェーダー設定で `Standard` を選べます。

本体と同梱ライブラリ・フォントの利用条件は、製品パッケージ内の利用条件とライセンス表示をご確認ください。

不具合報告・質問は [Issues](https://github.com/arcaia-net/mojihairpinmaker-kun-vpm/issues) へお願いします。
